# texlode: feedback and issues

This repository is where you report problems with [texlode](https://www.texlode.com) and suggest improvements. It holds issues and discussions only; texlode's source code is not here.

## Before you open an issue

- Search the [open issues](https://github.com/texlode/editor/issues). If yours is already there, add a 👍 to it instead of opening a new one. The count tells us what matters most to you.
- Some LaTeX behaves differently in texlode on purpose. The guide [Differences from LaTeX](https://www.texlode.com/guides/latex-differences/) lists these cases.
- Leave out anything private, such as manuscript text or names. A few lines of LaTeX that show the problem are enough.

## Issue types

Every issue has a type, shown next to its title. Pick the matching form when you [open an issue](https://github.com/texlode/editor/issues/new/choose).

### Bug

Something in texlode shows or builds wrong, or differently from what lualatex prints for the same source. For example, a package that looks wrong in the Print View, a PDF download that fails, or an import that loses figures.

Use the **Bug report** form. It asks what happened, how to reproduce it, a minimal LaTeX source and what you expected.

### Feature

Something you would like texlode to do that it does not do today.

Use the **Feature request** form. Describe the task you are trying to get done rather than the solution you have in mind, so there is room to find the best way to solve it.

### Testing

A request for help from us. Some fixes can only be confirmed on a device or setup we do not have at hand, such as a screen reader, a tablet or a particular browser. A Testing issue says what to try and what to look for.

We open these. If you have the setup, follow the steps and comment with what you saw.

## Labels

Labels show where an issue stands. `help wanted` marks issues where your input would move things forward, for example a sample document or a test on your setup.

## Ideas and questions

To talk an idea through before it becomes a feature request, or to ask how to do something in texlode, use [Discussions](https://github.com/texlode/editor/discussions).
